# GoDeeper 0.2.0

First public release of the community edition.

## Highlights

- Canvas and node system: tasks, questions, text, links, images and result nodes
- AI task execution and structured report export
- Publishing, public links and comments
- Account and admin basics

## Improvements

- Export dialog reorganized into a workspace with the format picker fixed at the bottom
- Dark mode readability and collision-aware auto layout

## Fixes

- Mention rendering, false quota errors, and nodes flying out of view after auto layout

## Install

See [Self-hosting](../self-hosting.md).

```bash
cd backend && npm install && npm run db:migrate && npm run db:seed && npm run dev
cd ../frontend && npm install && npm run dev
```

## Known limitations

- Payments and subscriptions are not implemented.
- Multi-canvas, trash restore, cross-canvas search, Pro AI tools, PDF export and team collaboration are not part of the community edition.
- The admin settings page is minimal; some operational settings are read-only.
